# Músculo Mental

Projeto Android do Músculo Mental. O planejamento original está preservado em `docs/`. A etapa 9 consolida o controle local do histórico, incluindo perfil, biblioteca demonstrativa, fichas, execução por série, cronômetro, histórico, recuperação, correção pós-finalização e exclusão confirmada de sessões concluídas. Consulte os arquivos `docs/ETAPA_*.md` para escopo, decisões técnicas, execução e validação.

## Leia nesta ordem

1. `AGENTS.md` — regras obrigatórias para trabalhar no projeto.
2. `docs/PLANEJAMENTO_COMPLETO.md` — planejamento original e histórico das decisões.
3. `docs/MVP_PROPOSTO.md` — recorte recomendado para a primeira versão testável.
4. `docs/ARQUITETURA_ANDROID.md` — proposta técnica inicial.
5. `PROMPT_INICIAL_CODEX.md` — primeira mensagem a enviar ao Codex.

## Estado atual

- Nome definido: Músculo Mental.
- Público: praticantes de musculação, do iniciante ao avançado, além de professores e personal trainers.
- Pilares: anatomia visual aplicada, execução de treinos, vínculo professor–aluno e Modo História.
- Aplicativo inicial recomendado: Android nativo com Kotlin e Jetpack Compose.
- Código: etapa 9 — MVP local com exclusão confirmada de sessões concluídas; séries e intervalos relacionados são apagados, enquanto a ficha de origem é preservada.
- Decisões pendentes: identidade visual, monetização, backend definitivo, iPhone/web e escopo futuro de alimentação e recursos sociais.

## Regra para começar

O Codex deve analisar os documentos, registrar dúvidas e apresentar um plano por etapas. Ele não deve gerar todo o aplicativo de uma vez nem transformar propostas em decisões definitivas sem aprovação do responsável pelo produto.
